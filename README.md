# Phishing Attack Simulation Report

## 1. What is Phishing?
Phishing is a cyber attack where attackers trick users into revealing sensitive information such as passwords, credit card details, or OTPs by impersonating a trusted entity.

## 2. Types of Phishing
- Email Phishing
- Spear Phishing
- Whaling
- Smishing (SMS phishing)
- Vishing (Voice phishing)

## 3. Phishing Simulation Overview
This simulation demonstrates how attackers:
- Send fake emails
- Redirect users to malicious websites
- Capture credentials
- Track user interaction

## 4. Fake Email Template
A phishing email was created pretending to be from an official service requesting urgent account verification.

## 5. Landing Page
A fake login page was created to simulate credential harvesting.

## 6. Tracking Responses
In real tools like GoPhish:
- Email opened
- Link clicked
- Credentials submitted
can be tracked using dashboards.

## 7. Red Flags Identified
- Urgent language
- Suspicious sender address
- Unknown links
- Spelling/grammar mistakes
- Generic greetings

## 8. Prevention Methods
- User awareness training
- Email filtering
- Multi-factor authentication (MFA)
- Checking URLs before clicking
- Never sharing credentials

## 9. Final Outcome
This simulation helps build awareness against social engineering and phishing attacks.
